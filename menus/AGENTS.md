# Old Philly Menus

This is the isolated Astro/TypeScript app in the OldPhilly monorepo. The canonical destination is https://oldphilly.org/menus/; the existing photo site remains at /. Preserve the Python crawler, photo-data generator and photo runtime unless a requested menu integration requires a narrow change. Keep application, import, build and test code in TypeScript. No React, backend or database is needed. Use small readable Astro components and the existing Simple.css base with the original restrained menu theme.

Use the pinned npm dependencies and lockfile. Run `ASTRO_TELEMETRY_DISABLED=1 npm run check` for native stable TypeScript 7, explicit Astro diagnostics, type-aware Oxlint, Oxfmt including Astro, behavior tests and static build. Astro's checker requires its supported pinned TypeScript 6 JavaScript API; native application checks retain `skipLibCheck: false`. No unsafe casts, `any`, blanket disables or suppression comments. Schemas are Zod-first and infer readonly domain types; parse source boundaries once.

`npm run build:site` builds the app and replaces only generated ../site/menus/. After composing, `CHROMIUM_PATH=/usr/bin/chromium npm run test:browser` owns a fresh static server for ../site; omit CHROMIUM_PATH for a Playwright-installed browser. Root CI builds photo data from its existing public input and checks both apps before the existing Cloudflare deployment. Menu code must not alter root photo files or generated data during composition.
