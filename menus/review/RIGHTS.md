# CIA release audit

The source records for all 30 imported CIA menus state **Copyright Not Evaluated** and identify [CNE 1.0](https://rightsstatements.org/vocab/CNE/1.0/). That statement reports an unevaluated status; it is not a license. The [CIA collection guide](https://library.culinary.edu/c.php?g=592165&p=4095052) describes searchable transcripts and access but provides no blanket republication permission. The current record viewer could not be fetched in this executor; no permission is inferred from source access, a zero OCR flag or an old catalog date.

The release therefore retains factual catalog metadata and library links and omits full CIA transcripts and scan images. The affected transcripts are records **2535, 2537, 2548 and 18438**. Their nonempty `transc` values become empty strings in `snapshots/cia-metadata.json`; every other source key/value remains exact. Existing single-page IDs/links remain, and all 30 records, 16 dated/14 undated, remain selectable. This change does not block release of the app's NYPL menu transcriptions and prices.

The private original remains unchanged at `raw/rights/cia-all30-parent-export.json` in the earlier private research checkout, outside this monorepo, with 70,874 bytes and SHA-256 `3abe44636acac88ecccd8d04f6570c952e53829eafd496c9c008c8508322aafb`. The public metadata derivative is 56,824 bytes with SHA-256 `38932b1b208c375a14f32f0dbf43b6ee2cd26173e3a91c8957d00b34441b9315`. `snapshots/cia-rights-audit.json` records source identities, statements and only the withheld texts' lengths/hashes, never their text. A private comparison verified that only those four values changed.

`scripts/prepare-cia-metadata.ts` reproduces this derivative from the hash-verified private original. The normal offline build uses only the derivative. Every CIA import removes full transcripts before exporting either page or catalog fields, and release-schema validation rejects either path if reintroduced. Tests use synthetic text, not copied research transcripts.

Screenshots, static `dist` and the source archive must be regenerated from the scrubbed output. Older development commits and older private review bundles contain research text and are not safe publication history. OldPhilly receives only the clean source tree from 553b7738c3851f1ff588eda0ff74b3ae84401c9c, copied as files without grafting the earlier history. Private raw research and old refs remain outside this monorepo.

The story's separate NYPL image 4046889 has a matching [official item-specific U.S. public-domain statement](https://old-digitalcollections.nypl.org/items/c2e99748-bc89-4d90-e040-e00a18061570), credit and a direct source-hosted URL. Other jurisdictions are undetermined. No scan/photo bytes are copied or rehosted. This audit records the project's conservative release choice; it does not claim a blanket source license.
